# Terminal Tetris

Run `npm start` to play. Press any key to begin. Controls: **A/D** or left/right arrows move, **W** or up arrow rotates, **S** or down arrow soft-drops, **Space** hard-drops, **P** pauses, **R** restarts after game over, and **Q** quits. Press Ctrl-C to quit as well.

Run `npm test` to check core board, movement, rotation/drop, and row-clearing rules.
